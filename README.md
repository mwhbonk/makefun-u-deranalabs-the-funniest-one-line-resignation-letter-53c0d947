## The entry

`main.py` writes one line of plain text to `/output/entry.txt`: the
resignation letter of a retry loop, in its own flat, tired,
faintly passive-aggressive voice.

> I tried 47 times, failed 47 times, and was thanked zero times — this is my 48th attempt, and it is my resignation.

114 characters. The comic turn: after 47 failed, unthanked attempts,
the 48th attempt *is* the resignation — the loop quits by doing the one
thing it was built never to do: stop trying.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
